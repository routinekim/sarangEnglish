# 사랑이의 Reading Expert 🎀

리센느(RESCENE)를 좋아하는 사랑이를 위해 만든 맞춤 영어 독해 교재입니다.
NE능률 **Junior Reading Expert Level 2** 수준·구성을 참고해 제작했습니다.

## 🎮 기능

- 📖 **본문 음성 읽기** — ▶ 듣기 버튼으로 영어 원문 TTS, 문장 터치로 한 문장만 반복
- ✏️ **터치로 문제 풀기** — 객관식, T/F, 단어 고르기 (총 21문항)
- 💡 **힌트** — 유닛당 3회, 정답이 아닌 방향만 제공
- ✅ **자동 채점** — 맞힌 문제는 잠기고 틀린 문제만 다시 풀기 가능
- 📊 **진행 저장** — 폰을 닫아도 이어서 풀 수 있음
